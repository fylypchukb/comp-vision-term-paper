# Evaluation & Reporting Tools

These three scripts collect data, compute metrics, and generate visual materials for
the academic report on the rule-based gesture classifier.  
The classifier is **not** trained — it is purely geometric — so training curves are
not applicable; the F1 bar chart includes a subtitle note to that effect.

---

## Prerequisites

Install the extra dependencies (if not already installed):

```bash
pip install -r cv-module/requirements.txt
```

---

## Workflow

### Step 1 — Collect the evaluation dataset

```bash
python cv-module/tools/collect_dataset.py
```

**Optional flags:**

| Flag | Default | Description |
|------|---------|-------------|
| `--samples N` | `30` | Frames to capture per gesture |
| `--camera N` | `0` | OpenCV camera index |
| `--output PATH` | `cv-module/tools/eval_data.csv` | Output CSV path |

**Example — 50 samples, secondary camera:**
```bash
python cv-module/tools/collect_dataset.py --samples 50 --camera 1
```

**What happens:**
- The webcam opens; the tool cycles through all 11 gestures in priority order.
- For each gesture a prompt is shown on screen:  
  `Show gesture: <LABEL> (X/11) — hold SPACE to capture, N to skip, Q to quit`
- Hold **SPACE** to capture frames; the tool runs HandDetector + GestureClassifier
  on every captured frame immediately.
- After each gesture it prints the per-gesture accuracy.
- A summary table is printed at the end.

**Output:** `cv-module/tools/eval_data.csv`  
Columns: `true_label`, `predicted_label`, `hand_detected`, `timestamp`

---

### Step 2 — Generate metrics and plots

```bash
python cv-module/tools/evaluate.py
```

**Optional flags:**

| Flag | Default | Description |
|------|---------|-------------|
| `--csv PATH` | `cv-module/tools/eval_data.csv` | Input CSV |
| `--camera N` | `0` | Camera index for the live benchmark |
| `--frames N` | `200` | Frames to capture for the performance benchmark |
| `--skip-benchmark` | off | Skip the live-camera performance test |

**Example — skip live benchmark (offline mode):**
```bash
python cv-module/tools/evaluate.py --skip-benchmark
```

**Console output:**
- sklearn-style classification report (Precision / Recall / F1 / Support per class)
- Overall Accuracy, Macro F1, Weighted F1
- Hand detection rate (% frames where MediaPipe found a hand)
- Performance stats: Mean FPS, mean latency ms, p95, p99, min, max

**Output files:**

| File | Description |
|------|-------------|
| `cv-module/tools/output/confusion_matrix.png` | 11×11 row-normalised heatmap (% of true class) |
| `cv-module/tools/output/f1_per_class.png` | Horizontal F1 bar chart, colour-coded by threshold |
| `cv-module/tools/output/performance.png` | Latency over 200 frames + frame-time histogram |

---

### Step 3 — Capture annotated screenshots for the report

```bash
python cv-module/tools/capture_visuals.py
```

**Optional flags:**

| Flag | Default | Description |
|------|---------|-------------|
| `--camera N` | `0` | OpenCV camera index |

**What happens:**
- The webcam opens; the tool cycles through all 11 gestures.
- For each gesture the prompt shows: `Show gesture: <LABEL> — press SPACE to capture, N to skip, Q to quit`
- On **SPACE**: captures one frame, runs the full pipeline, draws the MediaPipe
  hand skeleton, overlays:
  - `True: <LABEL>` — always in white
  - `Detected: <predicted>` — green if correct, red if wrong or no hand found
- Saves `cv-module/tools/output/gesture_<LABEL>.png`
- After all 11 gestures assembles a **4×3 montage** (11 gestures + 1 blank cell).

**Output files:**

| File | Description |
|------|-------------|
| `cv-module/tools/output/gesture_OK.png` | Individual annotated screenshot |
| `cv-module/tools/output/gesture_VULCAN.png` | … |
| *(one per gesture)* | … |
| `cv-module/tools/output/gesture_montage.png` | 4×3 grid, 320×240 cells, captions below |

## Gesture reference (priority order)

| # | Label | Description |
|---|-------|-------------|
| 1 | `OK` | Thumb + index form a circle, middle/ring/pinky extended |
| 2 | `VULCAN` | Four fingers extended, middle↔ring gap wide, pairs close |
| 3 | `OPEN_PALM` | All five fingers extended |
| 4 | `FIST` | All four fingers curled (thumb state ignored) |
| 5 | `FINGER_GUN` | Index extended + thumb raised above knuckle line |
| 6 | `INDEX_UP` | Only index extended, thumb curled |
| 7 | `PEACE` | Index + middle extended |
| 8 | `THREE` | Index + middle + ring extended |
| 9 | `FOUR` | Index + middle + ring + pinky extended (no Vulcan spread) |
| 10 | `PINKY_UP` | Only pinky extended |
| 11 | `ROCK` | Index + pinky extended (devil horns) |

> **Note:** THUMBS_UP and THUMBS_DOWN are intentionally absent from the classifier.
